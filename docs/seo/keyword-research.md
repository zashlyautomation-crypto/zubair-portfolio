  - `<h3>`: Individual service cards, project descriptions, and FAQ question accordion headers.
  - **Verdict:** Valid hierarchical heading structure with zero skipped levels.

- **Contact Page (`/contact`):**
  - Semantic `<h1>`: `<h1 className="cp-hero-text">LET'S CONNECT</h1>`
  - Direct communication paths: Email (`zashlycraft@gmail.com`), Phone (`+923294264963`), GitHub, Location (`Faisalabad, Pakistan`).

### 4.2 Natural Keyword Integration vs. Cannibalization
- **Strict Quality Control:** No keyword stuffing or repetitive artificial anchor lists. Target phrases appear naturally in project descriptions, technology cards, and factual FAQs.
- **Cannibalization Analysis:**
  - Route `/` targets broad hiring, developer brand, and portfolio queries (`freelance React JS developer`, `best freelancer in Faisalabad`, `interactive 3D website developer`).
  - Route `/contact` targets transactional inquiry phrases (`Contact Zubair`, `Hire React developer`).
  - Single canonical domain (`https://zubairkaportfolio.netlify.app/`) eliminates competing duplicates.
