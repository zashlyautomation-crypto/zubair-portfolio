## Running the Project

**IMPORTANT:** All commands must be run from the `portfolio/` subdirectory:

```bash
# Start development server
cd portfolio
npm run dev
# App available at: http://localhost:5173/
```

Other useful commands (run from `portfolio/`):
```bash
npm run build    # Production build → dist/
npm run preview  # Preview production build locally
npm run lint     # ESLint check
npm run deploy   # Deploy to GitHub Pages (requires auth)
```
